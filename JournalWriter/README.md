# Mood Journal

Mood Journal is a simple and private desktop journaling app designed to help you organize your thoughts, notes, and daily reflections.

## Features

* Create, rename, and delete journal tabs
* Separate writing space for each journal
* Automatic saving while you write
* Search across all journals and entries
* View and restore previous versions of your notes
* Dark mode and light mode support
* 10 customizable page color themes
* Local storage for complete privacy

## Getting Started

1. Create a new journal tab.
2. Start writing in the editor.
3. Your work is saved automatically.
4. Use search to quickly find entries.
5. Customize the app with themes and appearance settings.

## Privacy

All journal data is stored locally on your device. No account or internet connection is required.

Enjoy a clean, distraction-free writing experience with Mood Journal.
