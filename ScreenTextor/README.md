# ScreenTextor - User Guide

## What is ScreenTextor?

ScreenTextor extracts text from images and screenshots using OCR (Optical Character Recognition) technology.

---

## Installation

1. Open the **ScreenTextor Setup** installer.
2. Click **Install**.
3. Choose **Install for All Users** if prompted.

   * **Note:** The application may use over **300 MB** of disk space.
4. Launch **ScreenTextor** after installation.

---

## How to Use

1. Capture an image using one of the following shortcuts:

   * `Ctrl + Shift + !`
   * `Ctrl + Alt + C`

2. The captured image will automatically be sent to ScreenTextor.

3. Wait a few seconds while the text is extracted.

4. Copy the extracted text from the application.

---

## Tips

* Use clear, high-quality images for the best OCR results.
* Blurry or low-resolution images may reduce text extraction accuracy.
* Ensure the text in the image is visible and not heavily distorted.

---

## Troubleshooting

### No Text Detected

* Make sure the image contains readable text.
* Try capturing a clearer image with better resolution.

### Shortcut Not Working

* Ensure ScreenTextor is running.
* Check if another application is using the same keyboard shortcut.

### Slow Extraction

* Large or complex images may take longer to process.
* Close unnecessary applications to free up system resources.
